# Visuels de projets et d’activités

Ce dossier est prévu pour de futurs visuels (projets, activités associatives, présentations,
travaux de recherche). **Aucune section « Projets » n’est affichée pour l’instant**, car aucune
information de ce type n’a été fournie dans le CV.

## Convention de nommage suggérée

```text
assets/images/projects/nom-du-projet-01.jpg
assets/images/projects/nom-du-projet-02.jpg
```

- Format horizontal, ratio **16:10** ou **16:9**.
- Largeur conseillée : **1600 px** minimum.
- JPEG, qualité ~80, poids raisonnable (< 500 Ko par image).
- Utiliser des visuels réels ou des documents de travail dont la publication est autorisée.

## Ajouter une section plus tard

1. Créer la structure HTML de la section dans `index.html` (commentaire de section dédié).
2. Ajouter les cartes et les images avec un attribut `alt` descriptif.
3. Ajouter les liens de navigation correspondants si la section doit être visible.
4. Vérifier le rendu mobile avant publication.

Ne pas inventer de projets, de clients, de résultats ou de visuels. Si aucune information
n’est fournie, laisser cette section absente.
